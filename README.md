## Set-up

Install the dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

## Build and run for production

Generate a static production build

```bash
npm run build
```

Preview the production build locally

```bash
npm run preview
```

## Checks

```bash
npm run lint
```
